# We Care - Página Interativa para Pets 🐾

Este é um projeto desenvolvido com HTML e CSS, focado em criar uma landing page para promover o cuidado com pets. A página oferece um design responsivo e interativo, utilizando estilos modernos e uma paleta de cores suave para proporcionar uma experiência agradável ao usuário.

📋 Tecnologias Utilizadas
<ul>
  <li>HTML5: Para a estrutura do conteúdo</li>
  <li>CSS3: Para estilização e responsividade</li>
  <li>Google Fonts: Fonte Montserrat para um design moderno</li>
</ul>

🎨 Funcionalidades
<ul>
  <li>Navegação no Header: Links para diferentes seções com efeito hover</li>
  <li>Botões estilizados: Com design arredondado e responsivo</li>
  <li>Design Responsivo: Adaptação para diferentes tamanhos de tela</li>
  <li>Imagem Destacada: Uma ilustração central que complementa o tema do cuidado com pets</li>
</ul>

💻 Estrutura do Projeto
HTML
<ul>
  <li>Estrutura semântica, com header, main e section</li>
  <li>Links de navegação e botão de login</li>
</ul>

CSS
<ul>
  <li>Estilização moderna com foco em responsividade</li>
  <li>Efeitos de hover para links e botões</li>
  <li>Media queries para melhor experiência em dispositivos móveis</li>
</ul>

📱 Responsividade

A página foi projetada para ser acessível tanto em desktops quanto em dispositivos móveis, com ajustes automáticos no layout.

Este projeto foi criado como parte do aprendizado em desenvolvimento web, com foco em boas práticas e design moderno.
